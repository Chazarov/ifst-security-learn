 При сокрытии информации в графическом файле предлагается следующий подход. Каждый 8-битовый байт исходного графического файла участвует в изображении одного из пикселей. Для каждого пикселя определены 3 байта, представляющие красную, зеленую и синюю компоненты цвета пикселя. Каждый байт секретного сообщения разделяется на 3 поля размером 3, 3 и 2 бита. Этими 3-х и 2-х битовыми полями затем замещаются младшие, наименее значимые разряды трех цветовых байтов соответствующего пикселя. Пример программы на C#, реализующей описанный алгоритм находится в приложении к лабораторной работе.
Младшие разряды в цветовых байтах слабо влияют на вид конкретного пикселя, и, соответственно, на общий вид изображения. Значения младших разрядов в большинстве изображений носят случайный характер, поэтому скрытое сообщение в них можно выявить статистическими методами.
Для невозможности расшифровки исходные данные необходимо зашифровать симметричным алгоритмом, например, Rijndael с ключом в 256 бит в режиме, где не используется вектор инициализации. При этом в качестве ключа можно использовать вычисленный хэш от введенного пароля, вычисленный например, по алгоритму SHA256.
