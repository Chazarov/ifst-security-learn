«Разработка механизма авторизации в веб приложении с использованием JWT»
Задача: Разработать веб-приложение, которое будет осуществлять автоматическую авторизацию пользователя с использованием JWT токена.
Веб-приложение должно содержать 2 страницы:
Страница авторизации, где пользователю предлагается ввести логин и пароль в соответствующие формы
Страница с произвольным содержимым, доступная только авторизованным пользователям

При успешной авторизации программа должна выдавать пару access и refresh токенов, используя которые пользователь может переходить на страницу №2

Access токен должен иметь ограниченное время жизни, после которого должно запрашиваться обновление токена 

Должна быть реализована функция внесения существующего токена в «черный список», после чего пользователь будет вынужден пройти повторную авторизацию на странице №1

При разработке можно использовать любой фреймворк, позволяющий создавать веб приложения и имеющий у себя реализацию механизмов авторизации через JWT

При демонстрации работы необходимо показать:
процесс авторизации в созданном веб приложении 
процесс обновления токенов по истечении срока жизни
указать место хранения токенов в браузере клиента и связанные с ним уязвимости
