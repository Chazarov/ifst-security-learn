1) команда `stat` - проведение частотного анализа и сохранение данных для взлома
`cesar.exe stat <входной_файл> <выходной_файл.json>`
2) команда `enc` - шифрование
`cesar.exe enc <входной_файл> <выходной_файл> <ключ 0-255>`
3) команда `dec` - декодирование файла по ключу 
`cesar.exe dec <зашифрованный_файл> <выходной_файл> <ключ 0-255>`
4) команда `decstat` - атака (взлом) с использованием метода частотного анализа
`cesar.exe decstat <зашифрованный_файл> <эталон.json> <выходной_файл>`
